The analysis must answer:

2. Which funnel stage has the largest meaningful loss?
3. Which user segments convert poorly?
4. What factors appear related to checkout abandonment?

# 3. USER FUNNEL

Use this funnel in this exact logical order:

App Open
→ Search
→ Product View
→ Add to Cart
→ Cart View
→ Checkout Started
→ Payment Attempt
→ Order Completed

Users may drop after any stage.

A session cannot reach a later stage without logically reaching the required earlier stages.

---

# 4. DATASET

Create a realistic synthetic event-level dataset.

Target approximately:

* 5,000–10,000 users
* several thousand sessions
* 30,000–80,000 events
* enough completed orders for meaningful segmentation and experimentation

Do not generate completely independent random values.

Build moderate, believable behavioral relationships into the synthetic data.

Examples:

* returning users convert better than new users
* returning users have somewhat higher average order value
* Android has slightly more payment failures than iOS
* one city has somewhat higher checkout abandonment
* higher delivery fees reduce checkout completion
* some payment methods fail more frequently
* organic and paid-acquisition users behave differently
* repeat customers are better candidates for simplified checkout

Patterns must be noticeable through analysis but not exaggerated.

Use a fixed random seed so results are reproducible.

# 12. SIMULATED A/B TEST

Create a simulated experiment.

## Control

Current checkout flow.

## Treatment

1-Click Reorder & Micro-Cart

The treatment represents a simplified checkout experience primarily for repeat customers.

Generate or derive a clean experiment dataset.

Measure:

* conversion rate
* checkout completion rate
* average order value
* payment failure rate as a guardrail

Calculate:

* control conversion
* treatment conversion
* absolute uplift
* relative uplift
* confidence interval
* p-value
* statistical significance

Use a simple correct statistical test for two conversion proportions.

Prefer a two-proportion z-test unless there is a good reason not to.

Use a conventional alpha such as:

0.05

Explain the result in plain English.

Do not use advanced experimentation techniques.

Do not manufacture an unrealistically large uplift.

Clearly state that this experiment is simulated.
